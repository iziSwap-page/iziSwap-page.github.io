What is iZiSwap?

iZiSwap is iZUMi Finance's exchange product: a discretized-liquidity AMM for token swaps, liquidity positions, and limit-order style trading. The official product docs describe the DL-AMM model and app route.

iZiSwap supported networks

iZiSwap is a multi-chain DEX product from iZUMi Finance. The developer docs list iZiSwap core and periphery contracts on BNB Chain, zkSync Era, Linea, Mantle, Base, Scroll, Arbitrum, Polygon, opBNB and many additional EVM networks. Live token support still depends on the app route and liquidity available on each chain. For searchers, the useful answer is: iZiSwap is not only on BNB Chain anymore, but users should verify the selected network, token contract and pool liquidity inside the official iZUMi swap app before signing.

iZiSwap DL-AMM and limit orders

iZiSwap's defining feature is its discretized-liquidity AMM, or DL-AMM. The official product docs say iZiSwap launched initially on BNB Chain and uses discrete concentrated liquidity, allowing liquidity to be distributed at fixed prices rather than only across broad ranges. The docs also connect this design to limit-order style trading. That makes iZiSwap relevant for users searching for more control than a basic pool swap, but execution still depends on available liquidity at the relevant price points.

iZiSwap fees and price impact

iZiSwap fees and price impact are route-specific. The swap engine consumes available liquidity across price points, including normal liquidity positions and limit orders, as described in the developer docs. That means the quoted output can change with trade size, available liquidity, selected network and active price point depth. Users should compare estimated output, price impact, slippage tolerance, approval amount and gas before signing. A low headline fee does not guarantee the best result if liquidity is thin for the token pair.

How to use iZiSwap on iZUMi Finance

To use iZiSwap, open the official iZUMi swap page, connect a wallet, select the network, choose the token to sell and the token to receive, then review the quote. Check token contracts, price impact, slippage, route and approval amount. If using limit-order style features, review the price target and execution assumptions. Confirm only on the izumi.finance domain and keep enough native gas token for the selected chain.

iZiSwap FAQ

What is iZiSwap?

iZiSwap is iZUMi Finance's DEX product built around a discretized-liquidity AMM. It supports token swaps, liquidity positions and limit-order style trading across supported networks. Users interact through the iZUMi Finance app and sign transactions from their own wallet.

What is the iZiSwap token?

The token associated with iZUMi Finance is IZI. Market price and listings should be checked on established market-data pages such as CoinGecko, while product mechanics and contract deployments should be checked in iZUMi's official docs. Do not trust token contracts from unofficial replies or ads.

Which chains does iZiSwap support?

The developer docs list iZiSwap contracts on BNB Chain, zkSync Era, Linea, Mantle, Base, Scroll, Arbitrum, Polygon, opBNB and many more networks. Live swap availability depends on the app, chain and token liquidity, so always check the selected network in the official interface.

Can I place limit orders on iZiSwap?

iZiSwap's DL-AMM design supports limit-order style trading methods, according to the official product docs. Users should still review how the current interface presents those orders, what price point is selected, whether enough liquidity exists, and whether the order requires additional management after signing.

Is iZiSwap only on BNB Chain?

No. iZiSwap initially launched on BNB Chain, but the developer docs now list many mainnet deployments across EVM networks. BNB Chain remains a notable network for the product, but users should choose the chain based on the token pair and liquidity they need.

What makes iZiSwap different from a normal AMM?

iZiSwap uses a discretized-liquidity AMM model where liquidity can exist at fixed price points and swaps consume liquidity across those points. This differs from a basic x*y=k pool and supports more specialized liquidity and limit-order style behavior. The practical benefit depends on active liquidity for the specific pair.
